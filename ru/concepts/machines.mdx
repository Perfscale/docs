## Обзор

**Машина** — это любой хост (bare metal сервер, виртуальная машина или контейнер), на котором запущен агент perfscale и выполняются тестовые скрипты. Машины принадлежат **тенанту** (workspace) и ограничены его областью видимости.

## Статусы

| Статус | Значение |
|--------|----------|
| `online` | Агент подключён, готов принимать задачи |
| `offline` | Агент недоступен |
| `busy` | В данный момент выполняет задачу |
| `maintenance` | Вручную выведен из ротации |

## Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | string | Человекочитаемое отображаемое имя |
| `hostname` | string | DNS-имя или IP, используемые агентом |
| `ipAddress` | string? | Публичный IP (опционально) |
| `os` | enum | `linux` \| `windows` \| `macos` |
| `arch` | enum | `amd64` \| `arm64` |
| `cpuCores` | int? | Количество ядер CPU |
| `memoryGb` | int? | Объём оперативной памяти в гигабайтах |

## Настройка сети Linux

Начиная с **perfscaled v0.7.0**, Linux-агенты по умолчанию включают после
успешного heartbeat две настройки ядра:

```sh
net.ipv4.ip_local_port_range = 1024 65535
net.ipv4.tcp_tw_reuse = 1
```

Расширенный диапазон эфемерных портов и переиспользование `TIME_WAIT`
позволяют поддерживать большую скорость исходящих подключений. Перед
изменением агент сохраняет исходные значения в
`/etc/perfscale/network-tuning.json` (режим `0600`) и восстанавливает их при
отключении настройки. Для записи нужны соответствующие привилегии; ошибка
отображается в статусе, но не останавливает агента. На машинах не с Linux
функция имеет статус `unsupported`, а системные параметры не изменяются.

На странице **Machines → конкретная машина** настройку можно отключить для
этой машины. Статус показывает `pending`, `applied`, `disabled`, `error` или
`unsupported`. Отключение создаёт запрос на восстановление, который агент
обрабатывает на следующем heartbeat; сохранённое состояние переживает и
перезапуск агента.

## Регистрация машины

Машины регистрируются через API или административную консоль. Каждая машина привязана к тенанту и обменивается данными через постоянное WebSocket-соединение (появится в будущих версиях — пока управляется вручную).

## Выбор машины

При запуске задачи perfscale выбирает онлайн-машины в workspace тенанта. Если доступно несколько машин, нагрузка распределяется равномерно.
